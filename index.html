🔑 连接共用数据（Supabase）

在 supabase.com → 你的项目 → Settings → API 里复制这两项（这是公开信息，不是密码）。 粘贴后点「保存并连接」，之后所有设备会自动共用同一份数据。

☁️ 开启多人共用数据（约 5 分钟）

本页默认只把数据保存在浏览器里。要让手机扫码、别人的电脑看到同一份数据，用免费的 Supabase 开通一次即可，之后所有设备自动共用。你现有数据在首次连通后会自动上传，不会丢。

  1. 打开 supabase.com，用邮箱免费注册（无需验证即可用）。
  2. 点「New project」，随便起名，区域选 Singapore，设一个数据库密码，等约 1 分钟创建完成。
  3. 进入项目 → 左下角 Settings → API，复制 Project URL 和 anon public key。
  4. 打开 SQL Editor，把下面这段 SQL 粘进去，点右上角 Run（运行一次即可，重复运行也没关系）：
-- 建表（可重复运行）
create table if not exists public.records (
  id text primary key, type text, category text, amount numeric,
  donor text, note text, date text,
  "createdAt" text, "updatedAt" text, deleted boolean
);
create table if not exists public.cats (
  id text primary key, name text, gender text, vaccine text,
  "vaccineDoses" integer, neutered text, adopted boolean, fostered boolean,
  "fosterAddress" text, note text, "dewormRecords" jsonb,
  photos jsonb, "adoptionPhotos" jsonb, "fosterPhotos" jsonb,
  "createdAt" text, "updatedAt" text
);
create table if not exists public.config (
  id text primary key, payload jsonb, "updatedAt" text
);
-- 开放网页读写权限（RLS）
alter table public.records enable row level security;
alter table public.cats enable row level security;
alter table public.config enable row level security;
drop policy if exists "anon all records" on public.records;
drop policy if exists "anon all cats" on public.cats;
drop policy if exists "anon all config" on public.config;
create policy "anon all records" on public.records for all using (true) with check (true);
create policy "anon all cats" on public.cats for all using (true) with check (true);
create policy "anon all config" on public.config for all using (true) with check (true);
-- 猫咪照片桶
insert into storage.buckets (id, name, public) values ('cats','cats', true)
  on conflict (id) do update set public = true;
drop policy if exists "anon read cats" on storage.objects;
drop policy if exists "anon insert cats" on storage.objects;
drop policy if exists "anon update cats" on storage.objects;
drop policy if exists "anon delete cats" on storage.objects;
create policy "anon read cats" on storage.objects for select using (bucket_id = 'cats');
create policy "anon insert cats" on storage.objects for insert with check (bucket_id = 'cats');
create policy "anon update cats" on storage.objects for update using (bucket_id = 'cats');
create policy "anon delete cats" on storage.objects for delete using (bucket_id = 'cats');
  1. 点击网页状态条上的「⚙️ 填 Key」，粘贴第 3 步复制好的两项，点「保存并连接」。
  2. 成功后状态条变绿色「☁️ 已连接 Supabase」。之后把这个 index.html 上传到任何地方（Netlify／服务器），大家看到的都是同一份数据。

提示：如果仍失败，把红色提示里的具体报错发我，我再帮你排查。照片会自动存进 Supabase 的 Storage（桶名 cats，公开可读）。
